\section{共同研究者ノートに含まれる六つの取り組み}

\subsection{Principal chiral model: bare flatness loss と再パラメータ化自由度}

$SU(2)$ principal chiral model の current を $J_\pm$ とし，
\begin{equation}
L_+=a(\lambda)J_+,
\qquad
L_-=c(\lambda)J_-
\end{equation}
という Lax connection の ansatz を用いる．複素スペクトルパラメータ $\lambda$ に依存する追加の重みを用いず，flatness residual の二乗をそのまま損失関数とする基準計算である．

同時に，$a(\lambda)$ と $c(\lambda)$ をともに学習する場合，$a(\lambda)$ を既知関数として固定する場合，$a(\lambda)$ を既知関数の近傍に penalty で拘束する場合を比較する．flatness が係数間の代数関係だけを決め，スペクトルパラメータの取り方には再パラメータ化自由度が残ることを数値的に調べる．

\subsection{Principal chiral model: analytic per-$\lambda$ reweighting}

$a(\lambda)=\lambda$ を固定した場合に，flatness loss から $c(\lambda)$ に伝わる勾配強度の $\lambda$ 依存性を解析し，
\begin{equation}
w(\lambda)\propto \left|\lambda-\frac12\right|^{-2}
\end{equation}
という解析的な per-$\lambda$ weight を導入する．目的は，スペクトルパラメータ領域内で不均一な training signal を補償することである．

\subsection{Principal chiral model: component-norm normalization と adaptive $\lambda$ weighting}

解析解や principal chiral model 固有の勾配公式を用いずに training signal の不均一性を抑える方法を調べる．flatness residual を構成する各項の norm を用いる component-norm normalization と，学習中に測定した per-$\lambda$ loss の exponential moving average に基づく adaptive $\lambda$ weighting を組み合わせる．

\subsection{$S^2=SU(2)/U(1)$ sigma model: Jacobian null-space analysis}

Lie algebra current の $\mathfrak h\oplus\mathfrak m$ 分解を
$J_\pm=J_\pm^{(0)}+J_\pm^{(1)}$ とし，
\begin{equation}
L_+=aJ_+^{(0)}+bJ_+^{(1)},
\qquad
L_-=cJ_-^{(0)}+dJ_-^{(1)}
\end{equation}
という線形 ansatz を用いる．flatness residual を係数 $(a,b,c,d)$ の関数とみなし，その Jacobian の null space を調べる．nullity から flatness solution set の局所次元を推定し，null vector の成分から動かない係数と family に沿って変化する係数を識別する．さらに，null-vector field と収束点の集合から conserved relation を抽出し，$a=c=1$ と $bd=1$ を事前に仮定せずに再構成する．

\subsection{$S^2=SU(2)/U(1)$ sigma model: pseudo-arclength continuation}

Jacobian の null space で得られた局所 tangent direction を用いて predictor--corrector 型の pseudo-arclength continuation を行い，flatness solution manifold 上の連続な経路を追跡する．一複素次元の solution manifold は二実次元であるため，この計算は manifold 全体を二実次元領域として走査するものではなく，その内部の一実次元の continuation path を高精度に追う計算である．

\subsection{$S^2=SU(2)/U(1)$ sigma model: explicit spectral-parameter network}

複素スペクトルパラメータを入力とする neural network
\begin{equation}
\mathcal N:\lambda\in\mathbb C\longmapsto
(a(\lambda),b(\lambda),c(\lambda),d(\lambda))\in\mathbb C^4
\end{equation}
を学習し，flatness solution manifold の有限領域を一つの滑らかで微分可能な map として表現する．学習には component-norm flatness loss に加えて，$\lambda$ 非依存 map への collapse を防ぐ derivative term と，continuation で得た solution points を用いる anchor termを用いる．

\section{arXiv:2608.05146 との差分}

既発表論文では，principal chiral model について $a(\lambda)=\lambda$ を固定して $c(\lambda)$ を neural network で学習する explicit spectral-parameter experiment と component-norm normalized flatness loss が既に含まれている．また $S^2=SU(2)/U(1)$ sigma model については，$a,b,c,d$ の定数学習に加え，truncated Laurent ansatz によって explicit $\lambda$ dependence を学習し，$a=c=1$ と互いに逆数になる Laurent modes を回収している．したがって，「スペクトルパラメータを明示的な入力または ansatz の変数として学習すること」自体は新しい差分ではない．

\subsection{現時点での数え上げ}

共同研究者ノートに含まれる取り組みは六項目である．広く「既発表論文にない setup, comparison, result」を差分と数えれば六項目すべてに未発表部分がある．新しい方法として区別すると，五項目が少なくとも一つの未発表 method element を含み，そのうち四項目は既発表論文から明確に切り分けられる方法論的差分である．component-norm normalization と adaptive $\lambda$ weighting の組合せは前者を既発表論文から引き継ぐため部分的な差分であり，bare flatness loss の比較は主として基準計算と ablation の役割を持つ．

共同研究者ノートそのものに含まれていない追加課題として，Lax curvature が equation of motion をどの程度 encode しているかを off shell で調べる．以下の最初の検証はこの追加課題に属する．

\section{最初の追加検証：principal chiral model における off-shell factorization}

\subsection{物理的設定}

$SU(2)$ principal chiral model の群値場を $g(x)$ とし，light-cone coordinates における right-invariant current を
\begin{equation}
J_\pm:=g^{-1}\partial_\pm g
\end{equation}
と定義する．この current は Maurer--Cartan identity
\begin{equation}
\partial_+J_- - \partial_-J_+ +[J_+,J_-]=0
\label{eq:mc-pcm-validation}
\end{equation}
を恒等的に満たす．一方，principal chiral model の equation of motion は
\begin{equation}
\partial_+J_-+\partial_-J_+=0
\end{equation}
である．ここでは equation-of-motion residual を
\begin{equation}
E:=\partial_+J_-+\partial_-J_+
\label{eq:eom-residual-pcm-validation}
\end{equation}
と定義し，$E$ をゼロに設定しない off-shell data を用いる．

標準的な一複素パラメータ Lax connection を
\begin{equation}
L_+(\lambda)=\frac{1}{1-\lambda}J_+,
\qquad
L_-(\lambda)=\frac{1}{1+\lambda}J_-
\label{eq:pcm-standard-lax-validation}
\end{equation}
とする．Lax curvature は
\begin{equation}
F_{+-}(\lambda)
:=\partial_+L_-(\lambda)-\partial_-L_+(\lambda)
+[L_+(\lambda),L_-(\lambda)]
\label{eq:lax-curvature-validation}
\end{equation}
である．式~\eqref{eq:mc-pcm-validation} を用いると，equation of motion を課す前に
\begin{equation}
F_{+-}(\lambda)=Q(\lambda)E,
\qquad
Q(\lambda)=-\frac{\lambda}{1-\lambda^2}
\,\mathbf 1_{\mathfrak{su}(2)}
\label{eq:exact-q-validation}
\end{equation}
と因数分解できる．$\mathbf 1_{\mathfrak{su}(2)}$ は Lie algebra $\mathfrak{su}(2)$ の三成分に作用する恒等写像である．

\subsection{学習問題}

式~\eqref{eq:exact-q-validation} の右辺を学習器には与えない．Lie algebra basis を $T_a$ $(a=1,2,3)$ とし，$E=E^aT_a$ と $F_{+-}=F^aT_a$ の成分を用いる．neural network は複素スペクトルパラメータの実部と虚部
\begin{equation}
(\operatorname{Re}\lambda,\operatorname{Im}\lambda)\in\mathbb R^2
\end{equation}
を入力として，一般の複素 $3\times3$ matrix
\begin{equation}
Q^a{}_{b}(\lambda)\in\mathbb C^{3\times3}
\end{equation}
を出力する．対角 matrix であること，三つの対角成分が等しいこと，$\lambda$ に対して式~\eqref{eq:exact-q-validation} の有理関数になることは architecture に与えない．

各 training sample では $J_+$，$J_-$，$E$ を独立に乱数生成する．$C:=[J_+,J_-]$ とおき，
\begin{equation}
\partial_+J_-:=\frac{E-C}{2},
\qquad
\partial_-J_+:=\frac{E+C}{2}
\label{eq:offshell-sampling-validation}
\end{equation}
と定義する．この構成により式~\eqref{eq:mc-pcm-validation} は sample ごとに満たされるが，$E$ は一般にゼロではない．したがって，flatness を満たす on-shell data だけから $Q$ を推定しているのではなく，off-shell relation $F_{+-}=QE$ 自体を学習している．

損失関数は
\begin{equation}
\mathcal L_Q
=
\frac{\left\langle
\lVert F_{+-}(\lambda)-Q(\lambda)E\rVert^2
\right\rangle}
{\left\langle\lVert F_{+-}(\lambda)\rVert^2\right\rangle+10^{-30}}
\label{eq:q-learning-loss-validation}
\end{equation}
とした．training domain は
\begin{equation}
-0.75\leq\operatorname{Re}\lambda\leq0.75,
\qquad
-0.75\leq\operatorname{Im}\lambda\leq0.75
\end{equation}
であり，$\lambda=\pm1$ の poles は領域外に置く．neural network は三 hidden layers，各 128 units，tanh activation を用い，4000 training steps，batch size 4096，Adam optimizer，learning rate $2\times10^{-3}$ で学習した．この節の数値は random seed 1234 の一回目の検証結果であり，再現性の seed scan はまだ行っていない．

\subsection{一回目の数値結果}

held-out data に対する相対 residual は
\begin{equation}
\frac{\lVert F_{+-}-QE\rVert}{\lVert F_{+-}\rVert}
=2.83\times10^{-2}
\end{equation}
であった．学習後に初めて解析解~\eqref{eq:exact-q-validation} と比較すると，複素 $\lambda$ plane 上の grid 全体での相対 matrix error は
\begin{equation}
\frac{\lVert Q_{\mathrm{learned}}-Q_{\mathrm{exact}}\rVert_F}
{\lVert Q_{\mathrm{exact}}\rVert_F}
=2.83\times10^{-2}
\end{equation}
であった．さらに，学習された matrix 全体の Frobenius norm に対する off-diagonal entries の norm の割合は $7.49\times10^{-3}$，三つの diagonal entries の相対 spread は $4.89\times10^{-3}$ であった．したがって，matrix structure を事前に与えなくても，学習結果は数パーセントの関数近似精度で scalar multiple of the identity に近づいている．

図~\ref{fig:q-training-history} は式~\eqref{eq:q-learning-loss-validation} の training history である．二乗 residual 型の loss が約 $10^{-3}$ まで低下しており，その平方根の scale は held-out relative residual と整合する．

\subsection{singular values を用いた dynamics encoding の診断}

式~\eqref{eq:exact-q-validation} により，$\lambda\neq0,\pm1$ では $Q(\lambda)$ は三つの Lie algebra directions に対して full rank である．一方，$\lambda=0$ では
\begin{equation}
L_+(0)=J_+,
\qquad
L_-(0)=J_-,
\qquad
Q(0)=0
\end{equation}
となり，flatness は equation of motion ではなく Maurer--Cartan identity だけから成立する．したがって $\lambda=0$ は，Lax curvature が dynamics を encode しない既知の点として rank diagnostic の control に使える．

図~\ref{fig:q-singular-values} では，学習された $3\times3$ matrix の三 singular values が generic な $\lambda$ でほぼ縮退し，解析的な $|\lambda/(1-\lambda^2)|$ を追跡している．$\lambda=0$ では学習値は厳密なゼロにはならず，三 singular values はそれぞれ約 $6.57\times10^{-3}$，$4.04\times10^{-3}$，$9.66\times10^{-4}$ である．これは generic な $\lambda$ における $O(10^{-1})$--$O(1)$ の singular values に比べて強く抑制されている．

\begin{figure}[tb]
  \centering
  \includegraphics[width=0.82\linewidth]{../figures/01_pcm_fqe/q_singular_values_real_axis.png}
  \caption{$\operatorname{Im}\lambda=0$ における学習された $Q(\lambda)$ の三 singular values．破線は解析解の singular value $|\lambda/(1-\lambda^2)|$ である．$\lambda=0$ では解析的に三 singular values が同時にゼロになる．}
  \label{fig:q-singular-values}
\end{figure}

ここで，有限精度で学習した matrix に対して数学的な matrix rank をそのまま数えることは適切でない．厳密解でゼロである singular value も近似誤差によって非零になるため，通常の floating-point rank はほぼ常に full rank を返し得る．今後は，(i) $Q(\lambda)$ 全体の operator norm が characteristic scale に比べて抑制されているか，(ii) 非零の operator norm を持つ点では singular values の比から一部 directions の rank loss があるか，を分けて定義する．この修正は，equation of motion を全く encode しない flat connection と，一部の equation-of-motion directions だけを encode する connection を区別するために必要である．
