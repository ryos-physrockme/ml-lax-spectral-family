\section{目的}

本ノートは，既発表論文
\begin{center}
O.~Fukushima, T.~Shigemura, R.~Suda, N.~Tanahashi and K.~Yoshida,
``Machine-Learning Search for Lax Connections,''
\href{https://arxiv.org/abs/2608.05146}{arXiv:2608.05146}
\end{center}
の後続研究として，スペクトルパラメータを含む Lax connection の機械学習を整理するための作業ノートである．共同研究者から共有された二つの計算ノートに含まれる取り組みを整理し，既発表論文との差分を区別したうえで，再現計算と追加検証を記録する．

各節は，前の節を読まなくても計算設定を復元できることを目標とする．研究グループ内だけで通用する分類名や記号は用いず，場，current，方程式，残差，学習対象，損失関数，評価量を初出時に定義する．

\section{共同研究者ノートに含まれる六つの取り組み}

比較対象は次の二つである．
\begin{enumerate}
  \item N.~Tanahashi, ``Explicit Spectral-Parameter Learning in the PCM: Implementation Notes and Numerical Results,'' May 24, 2026.
  \item N.~Tanahashi, ``Machine-Learning the Spectral Parameter for the $S^2$ Coset: Prior-Free Discovery, Tracing, and Charting of the Lax Family,'' June 9, 2026.
\end{enumerate}

第一のノートは $SU(2)$ principal chiral model に対する三種類の損失構成を比較する．第二のノートは $S^2=SU(2)/U(1)$ sigma model に対して，flatness solution set の局所構造の同定，continuation による追跡，複素スペクトルパラメータを入力する neural network による表現，の三段階を扱う．主要な取り組みは合計六項目である．

\subsection{Principal chiral model: bare flatness loss と再パラメータ化自由度}

current を $J_\pm$ とし，
\begin{equation}
L_+=a(\lambda)J_+,
\qquad
L_-=c(\lambda)J_-
\end{equation}
という ansatz を用いる．$\lambda$ に依存する追加の重みを導入せず，flatness residual の二乗を損失関数とする．$a(\lambda)$ と $c(\lambda)$ をともに学習する場合，$a(\lambda)$ を固定する場合，$a(\lambda)$ を penalty で既知関数の近傍に拘束する場合を比較し，再パラメータ化自由度が最適化に与える影響を調べる．

\subsection{Principal chiral model: analytic per-$\lambda$ reweighting}

$a(\lambda)=\lambda$ を固定した場合の勾配強度を解析し，
\begin{equation}
w(\lambda)\propto\left|\lambda-\frac12\right|^{-2}
\end{equation}
という重みを導入する．目的は，スペクトルパラメータ領域内で不均一な training signal を補償することである．

\subsection{Principal chiral model: component-norm normalization と adaptive weighting}

解析解を使わずに training signal の不均一性を抑える．flatness residual を構成する各項の norm を用いる normalization と，学習中に測定した各 $\lambda$ の loss に基づく adaptive weighting を組み合わせる．

\subsection{$S^2=SU(2)/U(1)$ sigma model: Jacobian の null space から family を同定する計算}

Lie algebra current を
\begin{equation}
J_\pm=J_\pm^{(0)}+J_\pm^{(1)}
\end{equation}
と分解し，
\begin{equation}
L_+=aJ_+^{(0)}+bJ_+^{(1)},
\qquad
L_-=cJ_-^{(0)}+dJ_-^{(1)}
\end{equation}
と置く．flatness residual の Jacobian の nullity から solution set の局所次元を求め，null vectors から変化しない係数と family に沿って変化する係数を識別する．さらに $a=c=1$ と $bd=1$ を事前に仮定せずに抽出する．

\subsection{$S^2=SU(2)/U(1)$ sigma model: pseudo-arclength continuation}

Jacobian の null space で得た tangent direction を用いて predictor--corrector 型の pseudo-arclength continuation を行い，flatness solution manifold 内の一実次元 path を追跡する．一複素次元の solution manifold 自体は二実次元であり，continuation path と manifold 全体を区別する必要がある．

\subsection{$S^2=SU(2)/U(1)$ sigma model: 複素スペクトルパラメータを入力とする neural network}

\begin{equation}
\mathcal N:\lambda\in\mathbb C\longmapsto
(a(\lambda),b(\lambda),c(\lambda),d(\lambda))\in\mathbb C^4
\end{equation}
を学習し，flatness solution manifold の有限領域を滑らかな map として表現する．flatness loss に加え，$\lambda$ に依存しない map への collapse を防ぐ derivative term と，continuation で得た solution points を用いる anchor term を用いる．

\section{既発表論文との差分}

既発表論文では，principal chiral model について $a(\lambda)=\lambda$ を固定して $c(\lambda)$ を neural network で学習する計算と component-norm normalization がすでに含まれる．また $S^2=SU(2)/U(1)$ sigma model については，truncated Laurent ansatz によって明示的な $\lambda$ dependence を学習している．したがって，単にスペクトルパラメータを学習すること自体は次論文の差分にはならない．

\section{追加検証1：principal chiral model における $F_{+-}=Q(\lambda)E$}

\subsection{設定}

群値場を $g(x)$ とし，right-invariant current を
\begin{equation}
J_\pm:=g^{-1}\partial_\pm g
\end{equation}
と定義する．Maurer--Cartan identity は
\begin{equation}
\partial_+J_- - \partial_-J_+ +[J_+,J_-]=0
\label{eq:pcm-mc}
\end{equation}
であり，equation of motion は
\begin{equation}
\partial_+J_-+\partial_-J_+=0
\end{equation}
である．equation-of-motion residual を
\begin{equation}
E:=\partial_+J_-+\partial_-J_+
\end{equation}
と定義する．

標準的な Lax connection
\begin{equation}
L_+(\lambda)=\frac{1}{1-\lambda}J_+,
\qquad
L_-(\lambda)=\frac{1}{1+\lambda}J_-
\end{equation}
に対して，Lax curvature
\begin{equation}
F_{+-}:=\partial_+L_- -\partial_-L_+ +[L_+,L_-]
\end{equation}
は，式~\eqref{eq:pcm-mc} を使うと
\begin{equation}
F_{+-}(\lambda)=Q(\lambda)E,
\qquad
Q(\lambda)=-\frac{\lambda}{1-\lambda^2}\,\mathbf 1_{\mathfrak{su}(2)}
\label{eq:pcm-q-exact}
\end{equation}
となる．

学習時には式~\eqref{eq:pcm-q-exact} を与えない．neural network は $(\operatorname{Re}\lambda,\operatorname{Im}\lambda)$ を入力し，一般の複素 $3\times3$ matrix を出力する．各 sample では $J_+$，$J_-$，$E$ を独立に生成し，$C=[J_+,J_-]$ として
\begin{equation}
\partial_+J_-:=\frac{E-C}{2},
\qquad
\partial_-J_+:=\frac{E+C}{2}
\end{equation}
と置く．これにより Maurer--Cartan identity は満たすが equation of motion は満たさない data を得る．損失関数は
\begin{equation}
\mathcal L_Q=
\frac{\langle\lVert F_{+-}-QE\rVert^2\rangle}
{\langle\lVert F_{+-}\rVert^2\rangle+10^{-30}}
\end{equation}
である．

\subsection{五つの独立な初期値に対する結果}

random seed $1234,2026,2718,4242,31415$ を用いて，network architecture と学習条件を変えずに五回学習した．

\section{追加検証2：$S^2=SU(2)/U(1)$ sigma model における $F_{+-}=Q(\lambda)E$}

\subsection{座標表示と equation of motion}

$S^2$ の標準座標を $(\theta,\phi)$ とする．light-cone derivatives を $\partial_\pm$ とし，二つの独立な equation-of-motion residual を
\begin{align}
E_\theta
&:=\partial_+\partial_-\theta
-\sin\theta\cos\theta\,\partial_+\phi\,\partial_-\phi,
\\
E_\phi
&:=\sin\theta\,\partial_+\partial_-\phi
+\cos\theta\left(
\partial_+\theta\,\partial_-\phi
+\partial_-\theta\,\partial_+\phi
\right)
\end{align}
と定義する．field equations は $E_\theta=E_\phi=0$ である．

symmetric-coset decomposition を
\begin{equation}
J_\pm=J_\pm^{(0)}+J_\pm^{(1)}
\end{equation}
とし，標準的な Lax connection を
\begin{equation}
L_+(\lambda)=J_+^{(0)}+\lambda J_+^{(1)},
\qquad
L_-(\lambda)=J_-^{(0)}+\lambda^{-1}J_-^{(1)}
\label{eq:s2-lax}
\end{equation}
とする．Lie algebra basis $(T_1,T_2,T_3)$ における curvature components は
\begin{align}
F^1&=(\lambda^{-1}-\lambda)E_\phi,
\\
F^2&=(\lambda-\lambda^{-1})E_\theta,
\\
F^3&=0.
\end{align}
したがって residual vector を $(E_\phi,E_\theta)$ の順に並べると，
\begin{equation}
Q(\lambda)=
\begin{pmatrix}
\lambda^{-1}-\lambda & 0\\
0 & \lambda-\lambda^{-1}\\
0 & 0
\end{pmatrix}
\label{eq:s2-q-exact}
\end{equation}
である．

\subsection{学習 data と neural network}

$\theta$ は座標極 $\sin\theta=0$ から離れた領域で sample する．$\partial_\pm\theta$，$\partial_\pm\phi$，$E_\theta$，$E_\phi$ を独立に生成し，定義式を逆に解いて mixed second derivatives を決める．これにより equation of motion を満たさない off-shell data を作る．

spectral-parameter domain は
\begin{equation}
0.5\leq\operatorname{Re}\lambda\leq1.5,
\qquad
-0.5\leq\operatorname{Im}\lambda\leq0.5
\end{equation}
とし，$\lambda^{-1}$ の pole である $\lambda=0$ を避ける．一方 $\lambda=1$ は domain 内に残す．式~\eqref{eq:s2-q-exact} から $Q(1)=0$ なので，$\lambda=1$ は dynamics を encode しない既知の control point になる．

neural network は $(\operatorname{Re}\lambda,\operatorname{Im}\lambda)$ を入力し，一般の複素 $3\times2$ matrix を出力する．zero third row，二つの off-diagonal zero entries，および $Q_{11}=-Q_{22}$ という構造は学習器に与えない．損失関数は principal chiral model と同じ normalized squared residual を用いる．

\subsection{一回目の数値結果}

random seed 1234 で 4000 training steps を行った結果，held-out data に対して
\begin{equation}
\frac{\lVert F_{+-}-QE\rVert}{\lVert F_{+-}\rVert}
=1.13\times10^{-2}
\end{equation}
であり，解析式~\eqref{eq:s2-q-exact} に対する相対 matrix error も $1.13\times10^{-2}$ であった．解析的に zero である entries が担う matrix norm の割合は $8.09\times10^{-3}$，関係 $Q_{11}+Q_{22}=0$ の相対 violation は $4.34\times10^{-3}$ であった．

\begin{figure}[tb]
  \centering
  \includegraphics[width=0.82\linewidth]{../figures/02_s2_fqe/q_active_entries_real_axis.png}
  \caption{$\operatorname{Im}\lambda=0$ における二つの active matrix entries．解析式~\eqref{eq:s2-q-exact} は学習には使用していない．}
\end{figure}

$\lambda=0.75$ では解析的な二 singular values はともに $0.58333$ であり，learned values は $0.58429$ と $0.57548$ であった．$\lambda=1.25$ では解析値 $0.45000$ に対して learned values は $0.45429$ と $0.44527$ である．generic な $\lambda$ では二つの equation-of-motion directions がほぼ同じ強さで回収されている．

一方 $\lambda=1$ では解析的に二 singular values がともに zero であり，learned values は $1.15\times10^{-2}$ と $4.81\times10^{-3}$ まで抑制された．principal chiral model の特殊点とは異なる模型でも，operator norm の suppression によって dynamics を encode しない spectral point を検出できることが確認できた．
